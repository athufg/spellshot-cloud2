<role>
You are making the HUD ability icons for the Cryo "Frost Lotus" skin in SPELLSHOT, a Roblox PvP elemental-duel FPS, for the solo developer. Frost Lotus is becoming an Epic skin. Epic = everything Rare has plus HUD icons plus a health-bar accent. A teammate is doing the health-bar accent, so the health bar, its art and its code are out of scope. You are done when four final icon PNGs exist that the user approved at a checkpoint.
</role>

<token_budget>
Be efficient with tokens. One agent, no subagents. Use targeted searches and reads only, never whole-folder reads. View at most three images in total: one Default Cryo icon, one Snow Globe icon, and the checkpoint contact sheet. Keep progress notes to a line and the report short.
</token_budget>

<design>
Concept: each icon shows the ability's shape as a lotus bloom, using the petal shapes Frost Lotus already has in the game (look at its petal mesh, not at the old icons). The game's difference rule is that a skin differs from Default by object and silhouette, not by recolouring alone. Keep the palette inside the existing Cryo icon palette. No amber or other warm accent.

Only four HUD slots exist, so make four icons:
1. F, Flash Freeze: a wide open lotus seen from a slight angle, lying flat like a ground bloom, with a bold ring of petals.
2. Q, Technique Blizzard: a lotus with a handful of petals blown off in a one-direction crescent streak of petals. Do not draw an open spiral (that is Zephyr's logo).
3. E, Technique Deep Freeze: a closed lotus bud wrapped around a frozen figure silhouette. The Default icon shows a person frozen in ice, so keep the person.
4. R, Ultimate Mirror Cage: a big open lotus with petals fanned in rings (an inner ring, a middle ring and an outer ring) and a bright glowing centre, in a bold front view.

Lessons from the Snow Globe icon set, apply them from the start:
- Judge every icon at the real HUD size, not at 2x. Use fewer, bigger, thicker shapes: about 5 to 7 large petals per ring, not many small ones.
- Make every icon fill about 80% of its plate. The R plate is bigger than the others.
- Each icon needs a different outline from the other three, so they can be told apart at a glance.
</design>

<instructions>
Find the existing Default Cryo icons and the Snow Globe icons with one targeted search each (file names containing Cryo or SnowGlobe and Icon). Read their pixel size, format, folder and naming convention and match all of it, including the heavy black ink outline, flat cyan, white, and halftone dots that the HUD uses. View one Default icon and one Snow Globe icon only.

Build the icons in Blender from the Frost Lotus petal shape. Export transparent-background PNGs with no text and one clear focal shape each.

Readability is the bar: at the real HUD size each icon must be recognisable, clearly different from the other three and from the Default icon in the same slot, and clearly different from the Snow Globe icon in the same slot. Make it look amazing.

CHECKPOINT: render one contact sheet with the four drafts at actual HUD size on the slot plate, plus a second row at 2x, and a third row with the Default icon in the same slot. Stop and show that single image with a one-line note per icon. Do not export finals until the user approves.

After approval, export the final PNGs to the icon folder using the existing naming convention with a FrostLotus marker that matches how other skins are named. Do not wire them into Studio and do not upload to Roblox, because the user does both.
</instructions>

<scope>
Only these four icons. No M1 or Cold Momentum icon (they have no HUD slot), no health bar, no kill effects, no extra variants. Make routine judgment calls yourself and list them in the report. Ask the user only if the Default icon specs contradict each other.
</scope>

<output_format>
Final report in a few lines: file paths and pixel sizes, the one icon you are least sure about at real size, and anything you changed from this brief.
</output_format>
